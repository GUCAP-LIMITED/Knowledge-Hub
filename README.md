# UAPP Academy — Knowledge Hub

A single-page React application for the UAPP Academy Knowledge Hub: courses,
tutorials, resources, certificates, team progress, approvals, and admin tools.

## Tech stack

- React 18
- Vite
- lucide-react (icons)

## Getting started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run preview  # preview the production build
```
